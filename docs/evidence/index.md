# Scientific evidence

This portal routes to the evidence without duplicating it.  Reports,
quantitative metrics and manifests under `validation/` are the primary
artefacts; these pages explain their status and interpretation.

## Current routes

- {doc}`../reference/evidence_registry` — which artefact supports which claim.
- {doc}`../reference/claims_matrix` — claim status and provenance.
- {doc}`../explanation/current_evidence` — what is verified, supported or
  still unknown.
- {doc}`../explanation/reduced_integration_hourglass` — a documented negative
  qualification result.
- {doc}`../explanation/spectral_mechanics/ebi_srix_falsification` — the EBI-TET
  negative result and its scope.
- {doc}`../how-to/reproduce_ebi_falsification` — reproduce the registered test.
