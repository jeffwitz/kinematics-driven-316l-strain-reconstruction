# Run a coupled reconstruction

**Mode:** how-to  
**Domain:** reconstruction

Use this workflow when a spatially coupled candidate is being compared with a
local baseline. Keep the same DIC path, mesh, padding and loading history, and
record the coupling parameters before comparing fields. Interpret the
local/nonlocal distinction with
{doc}`../../explanation/reconstruction/nonlocal_micromorphic` and compare
outputs using {doc}`compare_fields`.
