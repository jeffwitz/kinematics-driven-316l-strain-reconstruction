# Run a local reconstruction

**Mode:** how-to  
**Domain:** reconstruction

Prepare a case with the declared DIC axes and masks using
{doc}`../data/prepare_dic_case`, choose the qualified constitutive backend, run
the local solver and inspect the mechanical residual before comparing fields.
Keep the input manifest and solver report beside the generated outputs so the
run can be reproduced without relying on an unrecorded command line.
