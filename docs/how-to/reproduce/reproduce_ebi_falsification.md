# Reproduce the registered EBI-TET falsification

**Mode:** how-to  
**Domain:** evidence

Restore the registered commit and configuration, run the smallest EBI-TET
case, and compare its residual and field metrics with the archived thresholds.
The result is a documented falsification for that registered SRIX case; do not
generalise it to every possible EBI formulation. See {doc}`../reproduce_ebi_falsification`.
