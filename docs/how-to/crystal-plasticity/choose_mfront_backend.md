# Choose the MFront backend

**Mode:** how-to  
**Domain:** crystal-plasticity

Use MFront when a robust generic 3-D reference response is required. Use the
native backend when the explicit coupled local algebra or future GPU path is
the purpose of the run. Keep the backend choice in provenance and compare both
on identical histories. Record the choice in the configuration described by
{doc}`../../reference/software/configuration` and consult the native contract
in {doc}`../../reference/numerics/native_srix_backend`.
