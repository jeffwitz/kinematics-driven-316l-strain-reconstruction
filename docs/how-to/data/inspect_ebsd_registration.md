# Inspect EBSD registration

**Mode:** how-to  
**Domain:** crystal-plasticity

Check the global EBSD/DIC dimensions, pixel sizes, origin, row/column order,
crop history and the declared `Q_global_to_material` convention before a
forward run. Keep spatial mapping F separate from sample-frame axis
transformations. Record the result in the provenance report.

See {doc}`../../reference/scientific/ebsd_orientation_contract`.
