# J2/Ludwik as the historical baseline

**Mode:** explanation  
**Domain:** constitutive

J2/Ludwik is an isotropic baseline used to qualify the reconstruction pipeline
and to expose the limits of a point-local model. It is computationally useful
and easy to diagnose, but it does not resolve crystal slip systems or EBSD
orientation. The current scientific path therefore treats it as a baseline,
not as a substitute for SRIX.
