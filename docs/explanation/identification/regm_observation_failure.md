# Why the current REGM observation transfer is a no-go

**Mode:** explanation  
**Domain:** identification

The registered exact-space ranking survives as a useful diagnostic, but after
the qualified DIC observation transfer the REGM/FEMU ranking falls to
Spearman ``0.326`` and log Pearson ``0.276``. The current observed-space
objective is therefore not authorised for P43 parameter identification.

The failure was tested rather than assumed. Observation placement, a latent
POD upper bound, a mechanical projection, an information-geometry comparison,
an algorithmic tangent and a sequential one-correction variant were each
examined. None restored the missing observed-space sensitivity. The conclusion
is a limitation of the present surrogate plus observation chain, not a claim
that every possible REGM formulation must fail.

See {doc}`regm_method` for the approximation and
{doc}`regm_information_geometry` for the sensitivity diagnosis.
