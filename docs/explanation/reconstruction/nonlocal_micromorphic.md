# The historical nonlocal and micromorphic branch

**Mode:** explanation  
**Domain:** reconstruction

The micromorphic/nonlocal branch was introduced to represent redistribution
over a material length scale that a local law cannot provide. It remains an
important scientific and historical comparison, but it is not the main
description of the current native SRIX production path. Its parameters,
coupling and limitations are recorded in the linked reference and validation
artefacts.
