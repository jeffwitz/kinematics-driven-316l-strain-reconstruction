# Reconstruction, identification and prediction are different claims

**Mode:** explanation  
**Domain:** reconstruction

Reconstruction asks whether a specified model and data produce an equilibrated
field compatible with the observations. Identification asks whether changes in
parameters are observable through that field. Prediction asks whether the
calibrated model transfers to a new loading or geometry.

A good reconstruction is not, by itself, evidence that every constitutive
parameter is identifiable or that the model predicts outside the measured
path. This separation is the basis for the FEMU/SVD interpretation in
{doc}`../identification/identifiability`.
