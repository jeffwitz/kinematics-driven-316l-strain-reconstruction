# SRIX P43 performance and load-step control

This page records the first performance phase after commit `22143ec`. The
mechanical formulation, the TRI2 discretisation, the SRIX parameters and the
FFTW configuration are unchanged. The only solver changes are the vectorised
TRI2 residual assembly and reuse of an accepted Newton line-search trial.

## Qualified post-`22143ec` profile

The exact run is archived in:

```text
validation/_generated/performance/
  crystal_tet2_srix_p43_m100_i16_post_22143ec.json
  crystal_tet2_srix_p43_m100_i16_post_22143ec.fields.npz
  crystal_tet2_srix_p43_m100_i16_post_22143ec_manifest.json
```

The run uses the registered P43 crop, a 100x100 pixel grid, 16 proportional
increments, homogeneous Bunge orientation `[35, 20, 15]` degrees, four MFront
threads, one FFTW thread, LGMRES, and Eisenstat--Walker forcing.

The measured elapsed time is 114.80 s. Relative to the pre-`22143ec`
reference at 156.36 s, this is a 26.7% reduction. The final verification
residual is `7.94e-9`, and the fields agree with the previous reference at
the `1e-12` level. The constitutive evaluation count is 117, compared with
194 before trial reuse.

The remaining profile is constitutive:

| Component | Time (s) |
| --- | ---: |
| Material and plane-stress condensation | 105.94 |
| MFront integration | 88.95 |
| LGMRES | 5.81 |
| Jacobian actions | 3.63 |
| Spectral preconditioner | 1.46 |
| Nonlinear divergence | 0.12 |

The conclusion is operational rather than speculative: replacing LGMRES is
not the next priority. The material and external plane-stress condensation
still dominate the calculation.

## Fixed increment sweep

The current P43 path is proportional, so the same final boundary field can be
sampled with different fixed numbers of increments. The sweep is generated by:

```bash
python scripts/analyse_srix_increment_sweep.py \
  --directory validation/_generated/performance \
  --output-json validation/_generated/performance/srix_p43_m100_increment_sweep.json \
  --output-csv validation/_generated/performance/srix_p43_m100_increment_sweep.csv
```

The table compares every run with the 16-increment reference. A converged
equilibrium residual is necessary but not sufficient for selecting a load-step
count.

| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 12.48 | 6 | 8 | 1.48e-10 | 7.66e-2 | 5.94e-2 |
| 2 | 19.81 | 11 | 14 | 6.31e-10 | 3.16e-2 | 3.19e-2 |
| 4 | 34.20 | 24 | 30 | 3.78e-9 | 1.32e-2 | 1.34e-2 |
| 6 | 47.05 | 38 | 48 | 5.74e-9 | 7.33e-3 | 6.75e-3 |
| 8 | 59.75 | 46 | 57 | 6.13e-9 | 4.45e-3 | 3.89e-3 |
| 12 | 87.98 | 69 | 86 | 7.71e-9 | 1.49e-3 | 1.30e-3 |
| 16 | 114.80 | 93 | 117 | 7.94e-9 | 0 | 0 |

The displacement error at eight increments is `2.08e-6`, while the stress
error is `4.45e-3`. At twelve increments these become `9.06e-7` and
`1.49e-3`. Thus eight increments are a useful performance point, but they are
not a qualified replacement for the 16-increment reference under the current
field-accuracy thresholds.

The integrated system fractions retain the same 95% dominant set in this
proportional sweep, but that does not imply equality of stresses or local
slip amplitudes. The comparison must retain both global field errors and
system-level slip errors.

## Interpretation and next step

SRIX is independent of physical loading rate, but its numerical response still
depends on how the imposed deformation path is subdivided. The sweep therefore
tests path integration, not a physical time convergence study. It does not
justify skipping increments solely because the residual converges.

The next safe optimisation is promotion of the final tangent trial to a
complete output without a second MGIS integration. That optimisation must have
an independent qualification mode which keeps the revert-and-reintegrate
verification. Adaptive stepping should only be implemented after this fixed
sweep and the promotion contract are qualified.

Méric--Cailletaud must not inherit the SRIX stepping policy: its increment
duration is part of the constitutive law, whereas SRIX uses the increment
primarily as a subdivision of the deformation path.
