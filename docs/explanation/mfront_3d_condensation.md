# Condensing a three-dimensional material law to plane stress

## Why this second architecture exists

The native MFront `PlaneStress` behaviour is the production backend for the
current isotropic J2/Ludwik case. MFront solves for its axial strain and
returns an already condensed in-plane tangent.

That four-component interface is not sufficient preparation for a generally
oriented crystal-plasticity law. Such a law couples all six components of a
symmetric three-dimensional state. The experimental
`mfront-3d-condensed-plane-stress` backend therefore starts from a genuine
MFront `Tridimensional` behaviour and performs the plane-stress elimination in
the Python/MGIS adapter.

This does **not** make the finite-element model three-dimensional. The mesh,
degrees of freedom, strain-displacement matrix, global residual, and global
Newton system remain strictly two-dimensional.

## Partition of the local problem

The in-plane engineering strain is prescribed by the CPS4 kinematics:

$$
\boldsymbol{\epsilon}_a =
[\epsilon_{11},\epsilon_{22},\gamma_{12}].
$$

The local adapter solves for:

$$
\boldsymbol{\epsilon}_b =
[\epsilon_{33},\gamma_{13},\gamma_{23}]
$$

such that the transverse stress residual vanishes:

$$
\boldsymbol{r}_b =
[\sigma_{33},\sigma_{13},\sigma_{23}] = \boldsymbol{0}.
$$

At local iteration \(k\), MFront supplies the stress and the consistent
three-dimensional Kelvin tangent. The update is obtained by a linear solve:

$$
\boldsymbol{\epsilon}_b^{k+1}
=
\boldsymbol{\epsilon}_b^k
-\mathbf{C}_{bb}^{-1}\boldsymbol{\sigma}_b^k.
$$

The implementation uses `numpy.linalg.solve`; it never forms an explicit
inverse. Convergence is checked independently at every Gauss point before any
element averaging.

## Consistent plane-stress tangent

With \(a=[11,22,12]\) and \(b=[33,13,23]\), partition the algorithmic tangent
as:

$$
\mathbf{C} =
\begin{bmatrix}
\mathbf{C}_{aa} & \mathbf{C}_{ab}\\
\mathbf{C}_{ba} & \mathbf{C}_{bb}
\end{bmatrix}.
$$

The tangent passed to the unchanged two-dimensional solver is the Schur
complement:

$$
\mathbf{C}^{PS}
=
\mathbf{C}_{aa}
-\mathbf{C}_{ab}\mathbf{C}_{bb}^{-1}\mathbf{C}_{ba}.
$$

Only after this condensation are Kelvin shear factors converted to the
engineering-shear convention used by the finite-element kernel. Selecting the
in-plane block of a three-dimensional tangent would be incorrect.

## Transactional state management

There are three distinct levels of state:

1. the state committed at the last converged global increment;
2. the trial state for the current global Newton iteration;
3. the successive local trials used to enforce plane stress.

Every local iteration restarts from level 1. A local integration never starts
from the plastic state generated by the preceding local iteration:

```text
committed state s0
    -> integrate with transverse strain k
    -> read stress and Cbb
    -> revert to s0
    -> integrate with transverse strain k+1
```

The last locally converged trial remains uncommitted. It is promoted only when
the global Newton increment converges. A local failure reverts the MGIS state
and is reported to the global solver, which may cut back the pseudo-time step.

## Common constitutive contract

`PlaneStressMaterialBatch` hides material-specific details from global Newton.
Its implementations are:

| Backend | Role |
|---|---|
| `PythonJ2PlaneStressBatch` | independent analytical J2 regression path |
| `MFrontNativePlaneStressBatch` | production MFront `PlaneStress` path |
| `MFront3DCondensedPlaneStressBatch` | generic 3D-to-plane-stress adapter |

Each evaluation returns in-plane stress and tangent, complete tensors, the
three-component transverse residual, material observables, and local
diagnostics. The global solver only calls `evaluate`, `commit`, and `revert`.

`FullTensorState` remains an output type for the present small-strain additive
model. It is deliberately not the universal constitutive interface: a future
finite-strain crystal-plasticity behaviour may use different kinematic and
thermodynamic measures.

## Verified Kelvin layout

For the installed MGIS interface, the six-component order was established
from behaviour metadata and six independent elastic probes:

```text
[11, 22, 33, 12, 13, 23]
```

Strain shears are
`[sqrt(2)e12, sqrt(2)e13, sqrt(2)e23]`, equivalently
`[gamma12/sqrt(2), gamma13/sqrt(2), gamma23/sqrt(2)]`. Stress shears are
`[sqrt(2)s12, sqrt(2)s13, sqrt(2)s23]`. The conversion functions preserve
double contractions and are tested for all three shear planes.

## Current validation

The same J2/Ludwik model is compiled twice:

- `PixelLudwikJ2Plasticity` with `PlaneStress`;
- `PixelLudwikJ2Plasticity3D` with `Tridimensional`.

Material-point histories cover elasticity, uniaxial and equibiaxial loading,
shear, unloading, and non-proportional loading. A central finite-difference
test redoes the complete local condensation for each in-plane perturbation and
checks the Schur-complement tangent away from the yield transition.

On the real DIC 10×10 case, both paths require 66 global Newton iterations and
no cutback. The maximum in-plane stress difference is
`4.804e-08 MPa`; the maximum Gauss-point transverse residual of the condensed
path is `2.705e-08 MPa`; no local solve fails. Preserved evidence is in
`validation/reference_data/mfront_3d_condensed_dic_10x10_v1`.

This establishes the adapter with isotropic J2. It does not yet validate a
crystal-plasticity behaviour, its material parameters, or its orientation
data.
