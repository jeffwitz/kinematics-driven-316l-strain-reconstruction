# FCC interaction-matrix mapping

**Mode:** reference  
**Domain:** crystal-plasticity

The FCC SRIX law uses twelve octahedral slip systems in the MFront order.  The
interaction matrix has seven slots: self, coplanar, Hirth, Lomer, the two
ordered glissile-junction ranks, and collinear.  The six-coefficient
publication convention writes the single glissile coefficient into both
ordered glissile slots.

The matrix is generated by
`fem_inhouse.core.fcc_interaction_matrix.from_publication_coefficients` and
checked against the TFEL/MFront ordering in the unit tests.  Slot order is
part of the state contract: every per-system slip, back-strain and hardening
array uses the same twelve-system order.  Do not copy a published six-number
literal by position without applying this mapping.

The numerical matrix may be non-symmetric when the two ordered glissile slots
differ; the registered SRIX sets use the same glissile value in both slots.
