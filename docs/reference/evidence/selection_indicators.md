# Selection indicators and observable modes

**Mode:** reference  
**Domain:** evidence

Identification records a sensitivity matrix (S_{ij}=\partial y_i/\partial
\theta_j), its singular values and the associated parameter-space singular
vectors. Reported indicators include normalised singular values, retained
observable modes and weak/null combinations. The thresholds and masks used for
selection must be stored with the run manifest.

Interpretation of these indicators belongs in
{doc}`../../explanation/identification/identifiability`; this page defines the
quantities and their required provenance.
