# Command-line reference

**Mode:** reference  
**Domain:** software

CLI entry points accept a case/configuration manifest, a constitutive backend,
output location and diagnostic/benchmark options.  Reproduction commands
must record the exact configuration, git SHA, backend identity and input
hashes; generated fields are outputs, not implicit inputs.

Use the dedicated How-to pages for complete commands.  This page defines the
stable option categories and provenance requirements rather than duplicating
workflow recipes.
