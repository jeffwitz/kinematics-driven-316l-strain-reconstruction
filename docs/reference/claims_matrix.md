# Claims matrix

**Category: Reference.** The status vocabulary is **verified**,
**supported**, **provisional**, **not demonstrated**, and **not claimed**.

```{include} ../_generated/claims_matrix.inc
```

“Verified” refers to a declared numerical or implementation contract.
“Supported” indicates coherent evidence that still lacks an independent
confirmation required by the scientific claim. “Not claimed” is a deliberate
scope boundary, not a failed test.
